# Dilip Kumar Mahato - Personal Website

## Publish on GitHub Pages
1. Upload every file in this folder to the ROOT of the repository (no sub-folders needed):
   - index.html       the website (styles, scripts, photos, pictures and logo are inside this one file)
   - cv-builder.html  the free Academic CV Builder
   - 404.html         "page not found" page
   - robots.txt       search-engine settings
2. Repository > Settings > Pages: Source "Deploy from a branch", branch "main", folder "/ (root)".
3. Wait about a minute, then open the site and hard-refresh (Ctrl+Shift+R).

## Optional settings (open index.html in a text editor and search for "EDIT:")
- FORMSPREE_ID: paste a free Formspree form ID to receive contact-form messages by email.
  Until then, the form opens WhatsApp with the visitor's message ready to send.
- LINKS: WhatsApp and GitHub are set. Add Scholar, ResearchGate or Medium links and their icons appear automatically.
- BLOG_POSTS: add posts and the Blog section and menu item appear automatically.

## Notes
- The CV Builder runs entirely in the visitor's browser; nothing typed is uploaded.
- The "Landscapes of Nepal" pictures are original illustrations made for this site.
- Use only photos you have the right to publish if you replace any picture.
